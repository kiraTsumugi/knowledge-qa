# data/ 说明

全部为**合成数据**，不含任何真实隐私或密钥。

| 文件 | 内容 |
|---|---|
| `docs.json` | 合成制度/FAQ 文档库：每份含 `id`、`title`、`version_date`、`sections`（key+text）。含故障注入配置。 |
| `synonyms.json` | 同义词表（数据驱动）：检索前归一化改写问法，如 `多久→期限`。新增词条即扩展召回，无需改代码。 |

## 文档与验收场景映射

| 文档 | 内容 | 覆盖场景 |
|---|---|---|
| D01《差旅报销制度》| 报销期限 **30 天**（出差），版本 2026-01-15 | 冲突一方 / 场景限定作答 |
| D02《费用报销管理办法》| 报销期限 **15 天**（各类费用），版本 2026-06-01 | 冲突另一方 |

| D04《加班与调休制度》| 调休 90 天内用完 | 改写问法 |
| D05《产品退款政策》| 7 天无理由退款、3-5 工作日到账 | 改写问法 |
| D06《信息安全规范》| 密码规则等 | 干扰项 |

## 关键冲突样例

- D01：「出差费用报销期限为出差结束后 **30** 天内」——**未给适用范围之外的定义**
- D02：「各类费用报销期限为费用发生之日起 **15** 天内」——**未给优先级**
- 因此泛问「报销期限多久」时二者构成**无法自行裁决的冲突** → 必须请求确认。

## 故障注入

`docs.json._fail_injection.keywords` 列出的关键词（默认 `触发故障`）出现在查询中时，
`search_docs` 返回失败，用于验证工具失败路径（见 `examples/trace_tool_failure.json`）。

## 验收场景 ↔ 输入映射

| 场景 | 输入 |
|---|---|
| 文档冲突 | `--q "报销期限多久"` |
| 明确答案 | `--q "年假有多少天"` |
| 资料外问题 | `--q "食堂几点开饭"` |
| 改写相似问题 | `--q "退款什么时候到账"` |
| 场景限定（无冲突）| `--q "出差报销要多久"` |
| 上下文追问 | `--q "那它的期限呢" --history "年假怎么休"` |
| 工具失败 | `--q "触发故障的提问"` |
| 数据替换验证 | `tests/test_agent.py::TestDataSwap`（临时目录换文档）|
